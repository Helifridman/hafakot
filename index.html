⚙️ נשאר רק לחבר את Firebase

האפליקציה מוכנה, אבל כדי שכל הטלפונים יראו את אותם נתונים בזמן אמת צריך מסד נתונים חינמי של Google. זה חד-פעמי ולוקח כ-5 דקות:

  1. היכנסי אל console.firebase.google.com והתחברי עם חשבון Google.
  2. לחצי Create a project → תני שם (למשל hafakot) → אפשר לכבות Analytics → צרי את הפרויקט.
  3. בתפריט הצד: Build → Realtime Database → Create Database → בחרי מיקום (Belgium) → בחרי Start in test mode → Enable.
  4. חזרי לעמוד הראשי של הפרויקט, לחצי על אייקון </> (Web) → תני כינוי לאפליקציה → Register → יוצג לך קטע קוד עם firebaseConfig.
  5. פתחי את הקובץ הזה (index.html) בפנקס רשימות, ובראש הקוד (חפשי firebaseConfig) הדביקי את הערכים שקיבלת במקום הטקסט "הדביקי-כאן".
  6. שמרי, העלי מחדש ל-GitHub Pages — וזהו! רענני את הדף.

💡 טיפ: ב-test mode הגישה פתוחה למי שיש לו את הקישור. מספיק טוב לשימוש פנימי בקבוצה.
